# Upload team photos

Open https://github.com/goldboy225/goldboy225.github.io and choose Add file → Upload files.

Rename each JPEG photo before uploading to the repository root:

- Funding Group 0071 Team: `funding-0071-team.jpg`
- FYP (Final Year Project) Team: `fyp-team.jpg`
- Research Club Team: `research-club-team.jpg`

Commit to main. GitHub Pages publishes the update automatically; refresh the website after deployment. Each image replaces its team placeholder. To replace a photo later, upload a new JPEG using the same filename.

Convert PNG or HEIC photos to JPEG first; changing only the file extension does not convert the image.
